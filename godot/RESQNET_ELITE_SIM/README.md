# RESQNET — System B | Elite Metro Disaster Twin

## Godot target
Godot 4.7.x

## Import
Open the folder containing `project.godot`, or use Godot Project Manager → Import → select:
`RESQNET_ELITE_SIM/project.godot`

## Controls
WASD / QE = camera
TAB = strategic / street camera
SPACE = pause/resume
T = earthquake demo
F = fire injection
R = reset

## Phase
Elite visual/simulation prototype: city, connected road graph, traffic, disaster VFX,
victims, drone movement, event feed, and simulation controls.

System A networking is intentionally not claimed as connected in this build.
